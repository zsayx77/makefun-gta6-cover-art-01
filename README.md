Vice Cover Studio — a GTA 6-style cover art maker that turns your photos into multi-panel poster covers with bold caption lettering and a Vice City sunset/neon grade, exported as PNG in 1080x1080, 1080x1350 and 1920x1080. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the app works offline, with no network request.
